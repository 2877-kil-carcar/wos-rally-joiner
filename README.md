# Whiteout Survival 集結主・乗り手選定（SR＋SSR 第1〜8世代）

確認日: 2026-10-02

## 内容

- `wos_rally_joiner_gen1-8.html`: iPhoneを含むモバイル対応の1ファイル動作確認版。データをHTML内に埋め込み済み。
- `wos_rally_joiner_gen1-8.json`: アプリ組み込み用マスターデータ。
- `VALIDATION.md`: 出典、照合結果、既知の不一致と判断根拠。

## 使い方

HTMLをSafari、Chromeなどで開いてください。サーバー世代を選び、盾兵・槍兵・弓兵の集結主を指定します。

- 「全スキル」: 選択した集結主3体の全遠征スキルが使う計算枠を金色で表示。
- 「⭐ 乗り手選定」: 各英雄の第1遠征スキルだけを表示し、集結主と同じ計算枠を示す。

## データ範囲

- 英雄: 34体（SR 9体、SSR 25体）
- 遠征スキル: 93件
- SRの`generation`は1、`alwaysAvailable`はtrue。第1世代以降の全フィルターで表示。
- R英雄、専用装備スキルは対象外。
- スキル名は収録していません。

## 計算枠

11枠に直接対応する効果だけを`slots`へ登録しています。防御力上昇、シールド、回避、会心、直接追加攻撃、スキル限定ダメージなどは、元データを保持しつつ`slots: []`です。
